# ⏰ Alarm Clock

A simple, clean, and functional **web-based Alarm Clock** application. This project was developed as a practical exercise to reinforce and master front-end development skills, with a specific focus on core JavaScript concepts.

## 🛠️ Project Structure
This lightweight project consists of exactly **3 core files**:
* `index.html` - The structural markup for the clock display and alarm controls.
* `style.css` - Custom styling and a responsive layout with CSS animations.
* `script.js` - The core application logic, timing functions, and audio handling.

---

## 🚀 JavaScript Concepts Practiced
The primary objective of this project was to implement and understand key JavaScript methods and web APIs. The following concepts are heavily utilized within `script.js`:

1. **`querySelector()`**: Used to precisely target and select HTML DOM elements for manipulation.
2. **`firstElementChild`**: Used to access and reference the immediate first child element within a container node.
3. **`insertAdjacentHTML()`**: Utilized to dynamically and efficiently inject HTML string templates (e.g., generating dropdown options for hours and minutes).
4. **`setInterval()`**: Implemented to run a continuous background loop that updates the current time every second and checks against the alarm.
5. **`Date() object`**: Used to fetch the accurate, real-time system clock values (hours, minutes, and seconds).
6. **`Audio() object`**: Leveraged to load, play, and loop the alarm ringtone asset when the target time is reached.
7. **`Click Event`**: Captured to handle the user interactions for setting or clearing the alarm triggers.
8. **`addEventListener()`**: Implemented as the standard event-listening mechanism to bind interactive click states to UI buttons.
